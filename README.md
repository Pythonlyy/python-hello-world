# 👋 What Is Python? – Your First Line of Code

Python is a beginner-friendly programming language that's used for everything from web development to AI.

Let’s start with the classic first line of code:  
`print("Hello, Python!")`  
This line tells Python to display something on the screen.

---

## 💻 Example with Explanation

```python
print("Hello, Python!")
```

This is your first instruction.  
`print()` is a function that sends text to the screen.

---

### 🔈 Output

```
Hello, Python!
```

---

### 📌 Key Notes

- `print()` is how Python shows you results.
- The message must be wrapped in quotes (`" "` or `' '`).
- This is often the very first thing every programmer writes.
- You can print text, numbers, or even emojis 🎉

---
